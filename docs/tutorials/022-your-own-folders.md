Keep folders you reach for again and again, such as sound effects and music, in every project.

## Steps

1. Press the + beside Folders, at the top of Sources, and choose a folder. {show: folders-add}
2. Open it and press [Bring in] on a file to make it a source of this project. {show: source-folders}
3. Press a folder's ... button for [Rename], [Change folder...], [Show in Explorer] and [Take out of Sources]. {show: source-folders "Press the ... button beside a folder's name"}
4. Drag a folder's name to move it in the list. {show: source-folders}
5. To add a file to a folder, drop it on the folder or one of its subfolders, from File Explorer or from this project's sources. {show: source-folders}

## Details

A folder you add is listed under its own name in every project, its video, sound and picture
files ready to bring in, and its subfolders open like a tree. Drop a file into the folder on disk
and it appears. Drop one on a folder in Sources and a copy goes into that folder on disk, so
File Explorer shows it too; the original stays where it was. A name already in the folder is
kept, and the copy gets (2) after its name. What is inside a subfolder sits a step in from its
name, with a faint line down from its arrow. [Bring in] makes the file a source of the project you are in,
so the project never needs the folder to open. Each file has a film or a sound icon before its
name, which turns green once the file is in the project.

Recordings is one of them, made for you: the newest recordings in OBS's folder, the one still
being recorded marked, and a message when a new one finishes. Taken Recordings out? + offers it
back as [Recordings from OBS].

A right click on a folder's name opens the same menu as its ... button. [Take out of Sources]
leaves the folder and its files as they are, and can be undone. An open folder with two or more
things in it has a sort button beside ...: [By name] or [Newest first].
