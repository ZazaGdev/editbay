Find a file by name across the project's sources and every folder at once.

## Steps

1. Click the search box at the top of Sources, or press `Ctrl+F`. {show: sources-search}
2. Type part of the name.
3. Bring in a file straight from the results.
4. Clear the box to put every section back as it was. {show: sources-search}

## Details

The search covers the project's sources and every folder in Sources, subfolders included. Each
shows what matched under its own heading with a count, and one with nothing found is hidden. A
file found deep in a folder says where it is.

Clearing the box puts every section back as it was.
