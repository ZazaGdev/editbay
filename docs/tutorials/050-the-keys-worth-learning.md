The keys that do most of the work, and how to change any of them.

## Steps

1. Learn the keys in the table under Details first.
2. Press `Ctrl+/` for the full key list. {show: open-shortcuts}
3. To change one, rebind it there to a key or to your mouse's middle or side buttons. {show: open-shortcuts}

## Details

| Key | What it does |
|---|---|
| `Space` | Play or pause |
| `J` `K` `L` | Play backwards, stop, play. Again for faster. `K` held with `J` or `L` steps one frame |
| `Left` `Right` | One frame. `Shift` for one second |
| `Up` `Down` | Previous and next cut |
| `[` `]` | Select the previous or next clip on the track, and go to its start. With nothing selected, from the playhead |
| `Ctrl+A` | Select every clip on the timeline, on every track. `Esc` clears the selection |
| `Home` `End` | Start and end |
| `S` | Split at the playhead |
| `I` `O` | Trim the clip's start or end to the playhead |
| `Shift+I` `Shift+O` | Mark In and Out |
| `Delete` | Take it out, leave a gap. `Shift+Delete` closes the gap |
| `N` | Snapping on the timeline on or off |
| `V` | Swap Source and Output |
| `F` | Monitor full screen. `Shift+F` fits the whole edit |
| `Ctrl+K` | Search every action by typing |
| `Ctrl+/` | The full key list |
| `Ctrl+,` | Settings, every preference in one place |
| `Ctrl+E` | Export |

Every key can be changed in the shortcuts window. The app shows what you bound.
