Save your project, and let Editbay keep saving it after each change.

## Steps

1. Press `Ctrl+S` to save. The first save gives a new project its file. {show: save}
2. Press `Ctrl+Shift+S` to save a copy. {show: save-menu "Open this, then choose Save as..."}
3. To stop saving on its own, untick [Save automatically]. {show: save-menu "Open this, then untick Save automatically"}

## Details

Once a project has been saved, Editbay saves it on its own, a little after each change, so you do
not have to remember to. This is on from the start. You can also untick it in Settings
(`Ctrl+,`), or press `Ctrl+K` and type "save automatically", which switches it without opening
anything. While it is on, closing the app saves without asking.

A project that has never been saved has no file yet, so it cannot be saved on its own: press
`Ctrl+S` once to give it one. Until then your work is still kept in a recovery copy.

Saving on its own only writes over the file as Editbay left it. If the file was changed
elsewhere, moved, or made by an older version, it stops and tells you once: press `Ctrl+S` to
keep your version.

If the app closes unexpectedly, little is lost: a recovery copy is written a moment after each
change. Next time you open Editbay it offers that work back, and says when it was written so you
can tell whether it is worth taking. For work you chose not to save, see Earlier versions of a
project.
