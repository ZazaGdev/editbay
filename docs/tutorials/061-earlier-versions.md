Nothing is thrown away: get back work you did not save, or a file a save wrote over.

## Steps

1. Press [Recent]. {show: recent-toggle}
2. Look under Earlier versions and choose one. {show: recent-toggle "Press Recent, then look under Earlier versions"}
3. Save it to keep it.

## Details

Work you choose not to save, the file a save writes over, and a recovery copy you set aside are
all kept. You can also press `Ctrl+K` and type "earlier versions".

One opens as unsaved, and saving it keeps what it replaces too.
