Give a project a name instead of Untitled.

## Steps

1. Press the name at the top left of the window. {show: project-name}
2. Type the new name and press `Enter`.

## Details

A new project is called Untitled. You can also type a name in [Project name] at the top of the
start screen: both are the same name.

Once the project is saved, renaming it renames its file too.
