Point Editbay at a recording that was moved, renamed or is on a drive that is not plugged in.

## Steps

1. Look for the red bar across the top of the window saying how many source files could not be found. {show: missing-media on:missing}
2. Press the [Find] button with the file's name. {show: relink on:missing}
3. Choose where the file is now.

## Details

Editbay never copies your recordings into the project. It remembers where each one is, so a file
that is moved, renamed or on a drive that is not plugged in can no longer be played. Its clips
show red on the timeline, and nothing else in the project changes.

The red bar has a button for each missing file. Once you choose where one is, Editbay looks in
that same folder for the other missing files and brings back every one it finds there, so a whole
folder moved at once takes a single answer.

If the file you choose is a different recording, Editbay asks before using it.
