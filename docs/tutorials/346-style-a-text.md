Set a text's font, colours, outline, shadow, glow and a box behind it.

## Steps

1. Select the text on the timeline. {show: clip on:text}
2. In the Inspector's [Text] section, set its [Font], [Size] and colour. {show: text-font on:text}
3. Tick [Outline], [Shadow], [Glow] or [Box behind it] so it reads over busy footage.
4. To start over, press [Reset to default].

## Details

The [Text] section holds everything about a text:

- **The words.** Several lines are fine; the preview follows as you type.
- **Font, size and colour**, bold and italic. Any font installed on your PC.
- **Align** the lines left, centre or right, and set the **line spacing**.
- **Outline** and **Shadow**, so it reads over bright and busy footage.
- **Glow**, a blurred halo round the letters, as far as you set it reaching, in its own colour.
- **Box behind it**, with its own colour, opacity, rounded corners and padding.

**Every number changes the text as you type it**: the size, the line spacing, the outline, the
shadow and the box. The arrow keys, or the mouse wheel over the box you are typing in, move it
one step at a time (ten with `Shift`). Everything you do in one box is one undo, and `Escape`
puts back the number it had when you clicked into it.

**A new text starts as the last one you changed looks**, in any project: its font, size,
colours, outline, shadow and box. [Reset to default] gives a text the style every text starts
with. To keep a look, see Keep a text style.
