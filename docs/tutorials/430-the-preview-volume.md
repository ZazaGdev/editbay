Set how loud Editbay plays while you work, without changing the edit.

## Steps

1. Press the volume button beside the level meter. {show: monitor-volume}
2. Drag the [Preview volume] slider to the level you like. {show: monitor-volume "Press this, then drag the slider"}

## Details

The volume button sets how loud Editbay plays, and only that.

It changes nothing in the edit and nothing in what you export. It never goes through undo. It is
remembered with the window rather than with the project, because it is how you like to listen,
not part of your cut.

While it is turned down the button shows the figure, so a preview left quiet weeks ago is not a
mystery when you come back and think something is broken.

If you want a clip itself quieter in the finished video, that is the clip's volume in the
inspector, not this: see Set a clip volume exactly.
