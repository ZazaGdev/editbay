Make a landscape version and a vertical version of the same edit in one project.

## Steps

1. Press the copy icon beside the shape list to duplicate this sequence. {show: sequence-duplicate}
2. Pick the new shape in the shape list. {show: export-preset}
3. Or press + beside the copy icon and choose a shape for an empty sequence. {show: sequence-add}

## Details

A project can hold several sequences of the same sources, one per shape. The tabs sit above the
timeline, one per sequence, once there are two: with only one, the shape list beside says what it
is. Double-click a tab to rename its sequence, or right-click it for more.

Add a sequence and choose Vertical, Landscape, Square or Handoff. Or **duplicate the one you are
on and change its shape**, which is usually what you want: every crop is laid out again for the
new frame rather than leaving your framing wrong.

This is how you get a landscape version for YouTube and a vertical one for phones out of one
project without maintaining two files that drift apart.

At export you choose this sequence or all of them, so both versions can be written in one go.
