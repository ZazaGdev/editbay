Write your sequence out as a video file.

## Steps

1. Press [Export...] in the top bar, or `Ctrl+E`. {show: open-export}
2. Choose this sequence or all of them, and one video or one file per clip. {show: open-export "Open Export, then choose what to export and how many files"}
3. Press [Choose...] beside the folder to pick where the files go, and give them a name. The small folder icon next to it opens that folder. {show: open-export "Open Export, then choose a folder"}
4. Check the list of files it will write, then press [Export]. {show: open-export "Open Export, then press Export at the bottom"}

## Details

Choose **this sequence or all of them**, then **one joined video or one file per clip**. Pick a
folder and a name pattern. Until a project has exported once, the folder is the one set in
[Settings], under [Export]; after that it keeps the folder it used.

The dialog **lists the files it is going to write before it writes them**, and asks rather than
overwriting anything that is already there. You see exactly what you are about to get.

Progress is shown per file. A long export can be left running while you do something else.

What comes out is the edit as you see it: hidden tracks are absent, muted tracks are silent,
captions are burned in, and every clip is at the volume you set.

The same dialog exports only part of the sequence, saves a subtitle file or a transcript beside
the video, and chooses between Best quality and Fast: each has its own entry in Export.
