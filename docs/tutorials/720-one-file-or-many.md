Write the sequence as one video, or each clip as its own file in one pass.

## Steps

1. Press [Export...] in the top bar. {show: open-export}
2. Under [Files], choose [One video] or [One file per clip]. {show: open-export "Open Export, then choose under Files"}

## Details

**One joined video** writes your whole sequence as a single file. This is the ordinary case.

**One file per clip** writes each clip on the timeline as its own file. This is how you cut one
long recording into five separate shorts in a single pass, rather than exporting five times.

The **Handoff** shape always writes one file per clip, because its purpose is feeding another
tool that will do its own arranging.

A sequence whose output size varies per clip cannot be joined, and the dialog tells you so
rather than producing something wrong.
