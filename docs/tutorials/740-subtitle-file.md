Save the captions as an .srt file beside the video, for YouTube and other players.

## Steps

1. Press [Export...] in the top bar. {show: open-export}
2. Choose one video under [Files]. {show: open-export "Open Export, then choose One video under Files"}
3. Tick [Also save the captions as a subtitle file (.srt), for YouTube]. {show: open-export "Open Export, then tick the subtitle file"}

## Details

**A subtitle file** beside one joined video: tick it and the captions are also saved as an
`.srt` file with the video's name, for YouTube and other players that show their own. The
captions stay burned into the video as well.

It needs captions in the sequence. See Make captions.
