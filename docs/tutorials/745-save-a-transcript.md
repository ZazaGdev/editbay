Save every word said in your video as a text file, for a description, show notes or a post.

## Steps

1. Press [Export...] in the top bar. {show: open-export}
2. With one video, tick [Also save the full transcript as a text file (.txt)]. {show: open-export "Open Export, then tick the transcript"}
3. Or press [Save only the transcript (.txt)] for the text with no video. {show: open-export "Open Export, then Save only the transcript"}

## Details

**A transcript** beside one joined video: tick it and every word said in the part you export is
saved as a `.txt` file with the video's name, as plain paragraphs to read, for a YouTube
description, show notes or a post.

You do not need captions for it. With captions, it takes their words, including the ones you
fixed by hand. Without them, the export listens to the speech itself first and puts nothing on
the video. The first time, it offers to download the speech model it listens with.

**Just the transcript, no video:** [Save only the transcript (.txt)] writes the text file into
the export folder for the part chosen, without exporting anything else. It is also in `Ctrl+K`.
