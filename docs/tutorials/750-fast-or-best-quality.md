Choose between the smallest file and a much quicker export, and crisp up soft webcam footage.

## Steps

1. Press [Export...] in the top bar. {show: open-export}
2. Choose [Best quality] or [Fast]. {show: open-export "Open Export, then choose Best quality or Fast"}
3. Tick [Sharpen the picture a little, for soft webcam footage] if the picture is soft. {show: open-export "Open Export, then tick Sharpen"}

## Details

[Best quality] encodes on the processor: the smallest file for its quality, and the slowest.
[Fast] encodes on an NVIDIA graphics card, several times faster, for a slightly larger file that
looks the same. It is good for drafts and long videos. On a computer without one, Fast is shown
switched off and says why.

Sharpening crisps up soft webcam footage in the exported file only. The
Output view shows the picture as recorded.
