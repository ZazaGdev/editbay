See which credits your video's description must carry, written out ready to paste.

## Steps

1. Export as usual. {show: open-export}
2. When it finishes, copy the credits it lists into the video's description.
3. To mark a file as needing a credit, right click it in your assets folder in Sources and choose [Credit for the description...]. {show: effect-more or:source-folder on:effect "Open your assets folder here, then right click a file and choose Credit for the description..."}

## Details

When the export finishes it lists the credits the video's description must carry, each line
exactly as it has to be given, or says none are needed, and writes them beside the video as a
`.credits.txt` of the same name.

A file needs a credit when a folder it is in holds a `credit.txt` (the first line of it is the
credit), or when you marked it yourself with [Credit for the description...].

A credit is listed once however many of its files the video uses. The export is never stopped
for a missing credit.
